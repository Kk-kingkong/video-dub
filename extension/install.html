第一次使用要准备什么

下载与扩展版本一致、适合你的 Engine ZIP：macOS Apple Silicon、macOS Intel 或 Windows 10/11 x64。macOS 解压后双击“Install LocalTube Dub Engine.command”；Windows 解压后运行“Install LocalTube Dub Engine.cmd”。安装包自带固定 Python、yt-dlp、FFmpeg 和配音依赖，日常使用不需要终端。

Microsoft 自然在线是默认配音；选择 Kokoro 后可在扩展里主动安装约 140 MB 的本地模型。macOS 还提供仅限 macOS 的系统音色保底。当前开发包尚未签名和公证，系统可能显示首次打开警告；0.2.5 安装器会在你主动运行后自动处理自身目录的下载隔离属性。

源码开发需要 Python 3.10+、yt-dlp 和正在运行的 LocalTube Dub Engine。macOS 一键依赖脚本会检查 Python 版本并创建项目独立环境。Microsoft 自然在线只发送待朗读字幕；Kokoro 在本机生成中英文配音；系统自带 say 仅限 macOS。只看有字幕视频时不需要 Whisper；没有字幕的视频可以使用本地或自己的 Groq / Deepgram / OpenAI 转写。

启动本地 Engine

完成安装后，开始翻译或配音时会按需启动 Engine，空闲 5 分钟后自动退出。检查状态不会唤醒 Engine；下面的按钮可手动启动、重启或修复。

如果刚安装后仍显示未连接，请完全退出并重新打开 Chrome，再点“一键启动 Engine”。

Engine 会监听 127.0.0.1:8787。插件会优先使用页面已有目标语言字幕；页面读取失败或只有原文字幕时，再用 Engine 调用 yt-dlp 提取字幕文本。同步配音会先调用本地 TTS 生成音频片段并按视频进度播放，失败时再退回浏览器朗读。

首次 Native Host 安装会清理旧版登录自启动。翻译、配音或导出操作通过 Native Host 按需启动 Engine；“修复按需启动”会更新运行环境并清理旧配置。如果终端看到 Address already in use，新版启动脚本和“一键重启 Engine”会自动清理确认属于 LocalTube Dub 的旧进程。如果刚安装 Native Host 后仍提示不可用，请完全退出并重启 Chrome。

升级开发版后要刷新

如果改了插件代码，先在 chrome://extensions 点 LocalTube Dub 的“重新加载”，再刷新已经打开的 YouTube 视频页。视频页右侧面板标题里的版本号必须和当前 manifest 版本一致，否则页面还在运行旧内容脚本。

429 限流处理

YouTube 返回 429 表示当前网络或 cookies 被临时限流。先等待几分钟，不要反复点击开始。Engine 默认读取 Chrome cookies；如果读取 cookies 失败，可以关闭 Chrome 后重启 Engine，或临时禁用 cookies。
